# 📊 PhonePe Transaction Analysis

## 📌 Project Overview

This project focuses on analyzing **PhonePe transaction data** to understand transaction trends, transaction types, state-wise performance, regional performance, and yearly transaction growth.

The project uses **Python, SQL, Power BI, and Excel** to perform data analysis and create interactive visualizations that help identify meaningful patterns in digital payment transactions.

---

## 🎯 Objectives

- Analyze overall transaction amount and transaction count.
- Identify transaction trends across different years.
- Compare transaction performance across different transaction types.
- Analyze state-wise and region-wise transaction performance.
- Identify states with high transaction volumes.
- Analyze the distribution of transaction amounts by transaction type.
- Understand the relationship between transaction count and transaction amount.
- Create an interactive Power BI dashboard for business insights.
